🧠 ReviewMind — Final Project Documentation

ReviewMind is a secure, production-ready, AI-powered PR review assistant that reads code diffs, generates smart suggestions based on team coding preferences, opens automated fix branches/PRs, and commits updated style guidelines (TEAM_STYLE.md) back to the repository as the team's preferences evolve.

Repository Link: https://github.com/Rahul21sai/reviewmind

🏛️ System Architecture

ReviewMind integrates seamlessly between developer workspaces, a persistent database layer, and GitHub using Webhook triggers and REST API updates:

  • Webhook Callbacks: Instantly intercepts pull_request and issue_comment actions.
  • Database Storage: Logs feedback stats, reviews run, and commits generated.
  • AI Logic Loop: Structures customized reviews based on historical accepts/rejects of suggestions.
  • Automated Commit: Dynamically commits a TEAM_STYLE.md file directly to the code repository when a threshold of 20 feedbacks is met.

⚙️ Core Module Descriptions

1. Web Server & API (app.py)

Orchestrates Flask routing, blueprint registrations, signature validation using HMAC-SHA256, and health status probes. Houses the thread-safe in-memory rate-limiter.

2. Database Persistence (db.py)

Integrates PostgreSQL ThreadedConnectionPool alongside SQLite fallback. Handles query translating dynamically (e.g. mapping SQLite's ? placeholders to Postgres's %s structure and serial keys).

3. AI Reviewer (reviewer.py)

Prepares prompts by injecting accepted/rejected developer styles. Uses OpenAI structured completions with automatic transient-error retry loops (exponential backoff) and applies security/risk level classifications.

4. Auto-Fix PRs (fixer.py)

Performs code mutations and commits code directly to a branch, publishing linked pull requests automatically.

🔒 Security Hardening Controls

  • Signature Verification: Uses HMAC-SHA256 with GITHUB_WEBHOOK_SECRET to authenticate webhook payloads.
  • Input Constraints: Restricts repository parameters via regex (owner/repo), limits maximum diff inputs to 1MB, and validates integers.
  • Rate Limiting: Custom in-memory decorator throttles IPs on expensive AI/GitHub commit endpoints (429 status code).

🚀 Running Locally & Deploying

1. Native Local Setup

# Install packages
pip install -r requirements.txt

# Launch web server
python -m reviewmind.app

2. Render Cloud Deployment

The system uses render.yaml for Infrastructure-as-Code deployment. Render connects to the GitHub repository and runs a Gunicorn web process:

gunicorn reviewmind.app:app

Requires environment settings for: OPENAI_API_KEY, GITHUB_TOKEN, GITHUB_WEBHOOK_SECRET, and DATABASE_URL.
